H6.4: deshacer en la tabla con operaciones inversas (no instantáneas): el valor de una celda, el nombre de una fila, añadir una fila (se deshace enviándola a la papelera), enviar una fila a la papelera, y añadir o borrar una propiedad. ## Hito 13 — bases de datos más potentes (1.2)
- [ ] Reordenar filas y tarjetas arrastrando. *(H13.1. Arrastrar el asa de una fila (solo sin orden activo; si lo hay, se explica) y tarjetas dentro de una columna del tablero; línea de destino y Esc como en H9.2; renumeración transaccional como `move_select_option`; un paso de Cmd+Z.)*
- [ ] Propiedad de selección múltiple. *(H13.2, **ADR** corto: tabla de unión `db_multi_values` o lista JSON. Filtros «contiene / no contiene», orden por la primera opción, tablero agrupado no admitido; Markdown y CSV como lista separada por comas.)*
- [ ] Propiedades URL, creado y editado. *(H13.3. URL: se abre con un clic (con aviso si no es http/https). «Creado» y «Editado»: de solo lectura, a partir de las fechas de la página, filtrables y ordenables. Migración para el `CHECK` del tipo.)*
- [ ] Cambiar el tipo de una propiedad. *(H13.4. «Cambiar tipo» con vista previa de cuántos valores se convierten y cuántos se pierden; conversión en una transacción y conservando el valor original como texto donde no encaje (ADR 0006, línea 79).)*
- [ ] Vista calendario. *(H13.5. Nueva `db_views.kind` (migración del `CHECK`); mes con las filas en su fecha según una propiedad elegida, reutilizando `CalendarMonth` (H6.6); arrastrar cambia la fecha; «+» en un día crea una fila con esa fecha; filas sin fecha en una lista aparte.)*
- [ ] Vistas lista y galería. *(H13.6. Lista compacta (nombre y propiedades visibles en una línea) y galería de tarjetas con la primera imagen de la fila (H7.2) como portada. Migración del `CHECK` de `kind` (junto con H13.5).)*
- [ ] Plantillas de filas. *(H13.7, amplía el ADR 0010. Una o más plantillas por base con bloques y valores por defecto; «Nueva fila» ofrece elegir; una por defecto.)*
- [ ] Importar CSV como base de datos. *(H13.8. Soltar un `.csv` o «Importar CSV…»: vista previa con el tipo adivinado de cada columna (cambiable), una transacción, en un hilo aparte, límite de tamaño como el Markdown. Complementa H11.5.)*
